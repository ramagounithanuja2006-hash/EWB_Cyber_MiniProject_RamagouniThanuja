
# CyberShield

A beginner-level Cybersecurity Awareness and Threat Analysis System.

## Technologies
- HTML
- CSS
- JavaScript

## Modules
1. Cybersecurity Risk Assessment
2. Phishing Message Checker
3. Login Activity Monitoring
4. AI Security Assistant

## How to Run
1. Download or open the CyberShield project folder.
2. Open index.html in Google Chrome.
3. Select any module from the navigation bar.
4. Test the sample inputs.

## Important
This is an educational prototype. Login data is fictional.
The phishing checker uses keyword matching and is not a
guaranteed phishing detector.
