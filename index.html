About CyberShield

CyberShield is an educational cybersecurity project that demonstrates risk assessment, phishing warning signs, suspicious login review and safe security practices.

  • Task A – Cybersecurity risks and CIA triad.
  • Task B – Phishing message analysis.
  • Task C – Suspicious login activity review.
  • Task D – AI security advice evaluation.

Task A – Cybersecurity Risk Assessment

Understand the three principles of information security.

🔒

Confidentiality

Information should be accessible only to authorized people.

🧩

Integrity

Information should remain accurate and protected from unauthorized changes.

⚡

Availability

Systems and information should be available when required.

Task B – Phishing Message Checker

Paste a suspicious message to check common warning signs.

This is an educational keyword checker. It does not visit links or prove whether a message is genuine.

Common Phishing Warning Signs

  • Urgent or threatening language.
  • Requests for passwords or OTPs.
  • Unexpected links or attachments.
  • Unknown sender details.
  • Unexpected prizes or offers.

Safety tip: Do not click suspicious links. Verify the sender independently.

Security Recommendations

  • Review unfamiliar sign-in notifications.
  • Enable multi-factor authentication.
  • Change compromised passwords.
  • Sign out of unfamiliar sessions.
  • Contact the IT/security team.

Task D – AI Security Assistant

Learn safe cybersecurity practices.

🔑

Password Safety

Use long, unique passwords for important accounts.

📱

MFA

Enable multi-factor authentication. Never share verification codes.

🔄

Updates

Keep your operating system and applications updated.

📩

Email Safety

Verify unexpected requests through trusted channels.
